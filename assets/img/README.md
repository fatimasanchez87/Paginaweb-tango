# Fotos de la web

Copia aquí vuestras fotos **con estos nombres exactos**. Mientras una foto no exista,
la web muestra un fondo degradado en burdeos y dorado, así que podéis ir añadiéndolas poco a poco.

| Archivo             | Dónde aparece                         | Formato recomendado        |
|---------------------|---------------------------------------|----------------------------|
| `hero.jpg`          | Portada (pantalla completa)           | Horizontal, 2000×1300 px   |
| `fatima.jpg`        | Ficha de Fátima                       | Vertical 4:5, 1000×1250 px |
| `pablo.jpg`         | Ficha de Pablo                        | Vertical 4:5, 1000×1250 px |
| `show-musicos.jpg`  | Show con músicos en vivo              | Horizontal 16:10           |
| `show.jpg`          | Show con música grabada               | Horizontal 16:10           |
| `milonga.jpg`       | Fondo de la sección Milongas          | Horizontal, 2000 px ancho  |
| `galeria-1.jpg` … `galeria-6.jpg` | Galería               | Cualquier orientación, ~1200 px |
| `og-image.jpg`      | Vista previa al compartir en WhatsApp/redes | 1200×630 px          |

Consejos:
- Comprimid las fotos antes de subirlas (p. ej. con https://squoosh.app), idealmente < 400 KB cada una.
- En la portada queda mejor una foto con la pareja a la derecha (el texto va a la izquierda).
